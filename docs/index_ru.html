Разрабатываемый эмулятор Nintendo GameCube

pureikyubu (プレイキューブ) — эмулятор Nintendo GameCube, созданный для изучения аппаратного обеспечения консоли и реверс-инжиниринга технологий, на которых делались игры. GameCube — инженерный шедевр Nintendo/ArtX, и разбирать его по частям, чтобы понять, как он устроен, — большое удовольствие.

Заметки о релизе 1.7 Что изменилось после 1.6 Исходники на GitHub

Что нового

Релиз 1.6 вышел 17 августа 2023 года. С тех пор у эмулятора появился второй интерфейс пользователя, графический конвейер на шейдерах, модульные тесты для графики и ядра DSP, загружающийся Linux с работающей сетью и длинный список исправлений в играх — включая вступительный ролик Metroid Prime.

Графика

Шейдеры XF/TEV

Фиксированный конвейер OpenGL больше не используется. Transform Unit и Texture Environment Unit эмулятора выполняются вершинным и фрагментным шейдерами GLSL 3.30, которым передаётся всё содержимое регистров.

Тесты

340 тестов графики

Стенд прогоняет настоящий конвейер CP → XF → SU → RAS → TX → TEV → PE на реальном контексте OpenGL и публикует HTML-отчёт с сотнями отрендеренных картинок.

Звук

DSP против эталонных векторов

Ядро DSP проверяется по 1822 векторам, снятым с настоящего железа, а поведение ARAM/AI приведено в соответствие с документацией.

Процессор

GC-Linux загружается

Исправлены декодирование GQR/paired-single, обход хеш-таблицы MMU, декрементер, mtcrf и lswi — ядро GC-Linux 2004 года доходит до консоли.

Интерфейс

Селектор игр везде

Селектор игр из Win32-версии портирован в SDL-сборку: баннеры, Game ID, сортировка, фильтры и переход к игре по первой букве.

Совместимость

Больше игр запускается

Играет вступительный ролик Metroid Prime, Zelda: The Wind Waker проходит загрузку, у ролика Ikaruga правильные цвета, а PONG снова запускается.

Скриншоты

Снято с текущей сборки (линейка релиза 1.7).

Как собрать

Windows

Откройте scripts/VS2022/pureikyubu.sln в Visual Studio 2022 или 2026 и нажмите Build. Есть конфигурации Debug и Release как для Win32-, так и для SDL-интерфейса.

Linux

Сборка через CMake + SDL2, проверена в том числе под WSL2:

sudo apt install libglew-dev
git clone https://github.com/emu-russia/pureikyubu.git
cd pureikyubu && git submodule update --init
cd build && cmake .. && make
./pureikyubu pong.dol
