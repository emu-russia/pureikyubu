A work-in-progress Nintendo GameCube emulator

pureikyubu (プレイキューブ) is an emulator of the Nintendo GameCube built to research the hardware of the console and to reverse engineer the technologies the games were made with. The GameCube is a masterpiece of the Nintendo/ArtX engineers — this project is a way to take it apart and understand it.

Release Notes 1.8 What changed after 1.6 Source on GitHub

What is new

Release 1.8 is the performance release: a Gekko x86-64 recompiler, Paired-Single on SSE and event-driven device threads that no longer spin on the time base. Together with the interrupt-line fixes this is what boots Zelda: The Wind Waker and lets Animal Crossing leave its exception handler.

CPU

Gekko recompiler

An x86-64 basic-block compiler keeps the guest registers in host registers and lifts the emulated CPU from 39.7 to 155.9 MIPS; ALU-heavy code runs 8.6x faster. jit 0 and jit 1 switch engines at run time.

CPU

Paired-Single on SSE

Every arithmetic PS instruction and both quantised loads and stores are translated to SSE/SSE2; a PS-heavy workload goes from 59 to 435 MIPS.

Performance

No more busy-waiting

The VI scan-out and the serial poll moved onto the CPU thread, and the CP, AI DMA and DSP threads block on events. Ikaruga reached 4.58x real time, Luigi's Mansion 4.26x.

Compatibility

Black screens fixed

The DSP and disk-interface aggregate interrupt lines now work and the serial poll follows the video-line schedule: Zelda: The Wind Waker boots to its title screen and Animal Crossing shows the Nintendo logo.

Disc images

RVZ support

Compressed GameCube images in Dolphin's RVZ container (Zstandard) can be mounted read-only, next to ISO and GCM images.

UI

Controller settings in SDL

The SDL build has a pad backend of its own and the full "Configure Controller N" dialog: keyboard and gamepad bindings, analog sticks and triggers.

Build it

Windows

Open scripts/VS2026/pureikyubu.sln in Visual Studio 2026 and press Build. Debug and Release configurations exist for both the Win32 and the SDL front end.

Linux

CMake + SDL2 build, verified under WSL2 as well:

sudo apt install libglew-dev
git clone https://github.com/emu-russia/pureikyubu.git
cd pureikyubu && git submodule update --init
cd build && cmake .. && make
./pureikyubu pong.dol
